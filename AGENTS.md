# YTDown - Project Instructions for Codex

## Project Overview
macOS desktop app for downloading YouTube/media videos using yt-dlp.
**Stack**: Tauri v2 (Rust backend) + Vue 3 (Composition API) + TypeScript + Pinia + Tailwind CSS

## Language
- UI labels and user-facing strings: Japanese (日本語)
- Code, comments, commit messages: English

## Architecture

### Backend (src-tauri/)
- **commands/**: Tauri IPC command handlers
  - `download.rs` — start/cancel/pause/resume downloads, fetch playlist items
  - `formats.rs` — fetch video info/formats via yt-dlp
  - `browser.rs` — get URL from browser (Safari/Chrome/Brave/Arc/Edge/Firefox/Biscuit)
  - `cookies.rs` — cookie validation
  - `file_ops.rs` — file move/delete/reveal
  - `library.rs` — list/search library items
  - `settings.rs` — get/set settings (key-value in SQLite)
  - `playlists.rs`, `url_lists.rs` — playlist/URL list management
  - `ytdlp_mgmt.rs` — yt-dlp binary detection, update, info
- **ytdlp/**: yt-dlp process management
  - `process.rs` — DownloadConfig struct, start_download(), fetch_info(), fetch_playlist_items()
  - `parser.rs` — parse yt-dlp JSON output and progress lines
  - `binary.rs` — detect/download yt-dlp binary
- **db/**: SQLite database (rusqlite)
  - `schema.sql` — downloads, settings, playlists tables
  - `queries.rs` — all DB queries
  - `models.rs` — Rust structs for DB rows
- **state.rs**: AppState (Mutex-wrapped DB connection, active downloads, ytdlp_path)

### Frontend (src/)
- **stores/**: Pinia stores
  - `downloads.ts` — download queue, progress events, playlist parallel download
  - `library.ts` — library items, filtering, selection, bulk delete
  - `settings.ts` — app settings with DB persistence
- **components/**:
  - `download/` — DownloadDialog, DownloadProgress, DownloadQueue, BatchUrlDialog
  - `library/` — ListView, GridView, ColumnView, FileActions, SelectionBar
  - `settings/` — GeneralSettings, FormatSettings, AuthSettings, AdvancedSettings, RuleSettings
  - `layout/` — AppToolbar, AppSidebar, AppStatusBar
  - `playlist/` — PlaylistDetail
- **composables/**: useDownload, useFileManager
- **types/index.ts**: All TypeScript interfaces

## Key Patterns

### Tauri IPC
- Commands defined with `#[tauri::command]` in Rust
- Called via `invoke<T>('command_name', { args })` from frontend
- Permissions declared in `src-tauri/capabilities/default.json`
- Auto-generated permission files in `src-tauri/permissions/autogenerated/`

### Lock Management
- All state access uses `tokio::Mutex` — always use scoped locks (block expressions) to avoid holding locks across await points
- Pattern: `let result = { let lock = state.x.lock().await; /* use lock */ }; // lock dropped`

### Playlist Downloads
- 2-step architecture: `fetch_playlist_items` (metadata) → individual `start_download` calls
- Frontend buffers progress events in `pendingEvents` map for race condition handling
- Fallback: `--flat-playlist` first, then `--dump-json --yes-playlist --no-download`

### Cookie/Auth
- Settings stored as key-value pairs in SQLite `settings` table
- Cookie settings read from DB in `get_cookie_settings()` helper
- Applied to: `start_download`, `resume_download`, `fetch_formats`, `fetch_playlist_items`

### YouTube-specific
- YouTube URLs get channel-name subfolders: `%(channel)s/%(title)s.%(ext)s`
- Detection via `is_youtube_url()` in download.rs

## Build & Dev

```bash
# Frontend dev
pnpm dev

# Tauri dev (frontend + backend)
pnpm tauri dev

# Type check
npx vue-tsc --noEmit

# Rust check
cargo check --manifest-path src-tauri/Cargo.toml

# Build
pnpm tauri build

# Universal release build for macOS (ad-hoc signed via bundle.macOS.signingIdentity "-")
rm -rf src-tauri/target/universal-apple-darwin/release/bundle
pnpm tauri build --target universal-apple-darwin --bundles app,dmg --ci
```

## Conventions
- Use `cargo check` and `npx vue-tsc --noEmit` to verify after changes
- For bug fixes and new features, always run the relevant automated tests before finishing the task
- Frontend logic/UI changes should run `npx vitest run`
- If Playwright E2E tests exist for the affected area, run the relevant Playwright tests as well
- Do not rely on a plain `pnpm tauri build --target universal-apple-darwin` for release artifacts; remove `src-tauri/target/universal-apple-darwin/release/bundle` first and rebuild with `pnpm tauri build --target universal-apple-darwin --bundles app,dmg --ci`
- Prefer scoped Mutex locks over long-held locks
- New Tauri commands need: Rust function, lib.rs registration, capabilities/default.json permission
- Settings use `#[serde(default)]` on Rust DownloadOptions for backward compatibility
- Empty string fields → `None` via `non_empty()` helper before passing to yt-dlp
